# PIC18F4580 – 7-Segment Display Interfacing

## 📌 About the Project
This repository contains my Embedded C practice program for interfacing a 7-segment display with the PIC18F4580 microcontroller.

## 🎯 Objectives
- Understand how a 7-segment display works.
- Learn the segment patterns used to display numeric digits.
- Practice GPIO configuration and output control.
- Understand the basics of multi-digit display multiplexing, where implemented.

## 🛠️ Hardware and Software
- **Microcontroller:** PIC18F4580
- **Programming Language:** Embedded C
- **IDE:** MPLAB
- **Simulation:** Proteus Design Suite, if used

## 💡 Key Concepts
A 7-segment display consists of seven LED segments, labelled **a–g**, and sometimes a decimal point. By switching selected segments ON or OFF, we can display digits from 0 to 9.

The segment patterns depend on the display type, such as common-anode or common-cathode, and the output logic used in the circuit.
